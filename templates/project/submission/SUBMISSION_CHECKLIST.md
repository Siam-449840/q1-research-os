## Journal requirements (from the current Guide for Authors, downloaded by the owner)
- [ ] Scope fit confirmed against aims & scope and 3+ recent articles in the journal
- [ ] Quartile and indexing verified by the owner (SJR/JCR) and recorded in JOURNAL_CHECK.csv
- [ ] Not a predatory journal (checked against Think. Check. Submit.)
- [ ] Word, abstract, figure and table limits met
- [ ] Reference style applied
- [ ] Required statements present: data, code, AI use, CRediT, competing interests, funding
- [ ] Highlights / graphical abstract prepared if required
- [ ] Journal AI-use policy read and declaration matches it

## Integrity
- [ ] All rosctl gates S0-S8 pass (paste output into ledgers/DECISION_LOG.csv)
- [ ] Reference audit clean (academic-refchecker / bibvet output saved in review/)
- [ ] Similarity check run by the owner through the institution (Turnitin / iThenticate)
- [ ] Reporting-guideline checklist completed and attached as supplementary material
- [ ] Code + processed data archive ready for Zenodo (owner uploads and inserts DOI)

## Package
- [ ] Cover letter final (COVER_LETTER.md)
- [ ] Suggested reviewers (from cited authors only, no conflicts) prepared for the owner
- [ ] Manuscript exported to the journal format (.docx / LaTeX template)
- [ ] Supplementary material compiled

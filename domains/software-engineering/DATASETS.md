# Open data for empirical software engineering

> Record version/access date and license for each source in S3. Respect API terms and rate limits;
> never collect personal data beyond what the study needs (developer emails are personal data).

| Source | What | URL |
|---|---|---|
| GitHub REST/GraphQL API | Repositories, issues, PRs, commits, CI runs | https://docs.github.com/en/rest |
| GH Archive | Public GitHub event timeline (hourly archives, BigQuery) | https://www.gharchive.org/ |
| Software Heritage | Universal archive of source code with provenance | https://www.softwareheritage.org/ |
| PyPI / npm / Maven Central metadata | Package ecosystems, dependencies | https://pypi.org/ ; https://www.npmjs.com/ ; https://central.sonatype.com/ |
| deps.dev | Dependency graphs and advisories across ecosystems | https://deps.dev/ |
| NVD / OSV | Vulnerability databases | https://nvd.nist.gov/ ; https://osv.dev/ |
| Stack Exchange data dump | Q&A posts | https://archive.org/details/stackexchange |
| Defects4J / BugsInPy | Reproducible real bugs (Java / Python) | https://github.com/rjust/defects4j ; https://github.com/soarsmu/BugsInPy |
| Research software repos | Scientific models with multiple implementations (e.g. AquaCrop, WOFOST/PCSE) | project repositories |

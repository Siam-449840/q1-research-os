# Reporting standards (empirical SE)

- **ACM SIGSOFT Empirical Standards**: pick the standard(s) for your study type (e.g. Repository
  Mining, Experiments, Benchmarking, Qualitative Surveys, Replication) and complete its checklist:
  https://github.com/acmsigsoft/EmpiricalStandards
- **Threats to validity** section structured as construct / internal / external / conclusion validity.
- **Replication package**: code, data (or exact collection scripts + dates), environment, README,
  license, archived with DOI (Zenodo / Software Heritage).
- **Artifact evaluation** guidelines of the target venue (badges: available, functional, reusable).
- For ML-based studies also apply **REFORMS** (https://reforms.cs.princeton.edu/).
